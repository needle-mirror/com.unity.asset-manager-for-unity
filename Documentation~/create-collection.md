# Create a collection

### Create a collection in a project in Asset Manager for Unity 
---

Collections are folders that let you group assets in a hierarchical structure within your project.  

To create a collection in a project:

1. Right-click the project where you want to create the collection.
2. Select **Create new collection**.
3. Enter a name for the collection.
4. Press Enter or click outside the field to confirm.

The collection appears below the selected project. You can right-click the collection to rename or delete it.
